# Neja Music

This repository holds the installable Neja Music app for Android.

**Install it:** https://jeanoperario0-sketch.github.io/neja-music/

Open the link on your Android phone, tap **Download for Android**, open the file and tap **Install**.
Neja Music updates itself from this page: new versions download in the background and Android asks you to tap Install.

Every version is listed under [Releases](https://github.com/jeanoperario0-sketch/neja-music/releases).
