# Encore

This repository holds the installable Encore app for Android.

**Install it:** https://jeanoperario0-sketch.github.io/encore-app/

Open the link on your Android phone, tap **Download for Android**, open the file and tap **Install**.
Encore updates itself from this page: new versions download in the background and Android asks you to tap Install.

Every version is listed under [Releases](https://github.com/jeanoperario0-sketch/encore-app/releases).
